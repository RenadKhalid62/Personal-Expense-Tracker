# Personal-Expense-Tracker

Personal Expense Tracker

A simple Java application for managing personal expenses.

## Features

• Add expenses by entering an amount and category.
• Organize expenses into Food, Shopping, and Transport.
• View total expenses for each category.
• Export expense summaries to a CSV file.
• Display expenses using a bar chart.
• Handle invalid inputs.
